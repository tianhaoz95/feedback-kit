# feedbackkit-tauri

The frontend half of FeedbackKit for Tauri. Use it with the Rust plugin
`tauri-plugin-feedbackkit`, which adds the real OS, device and app details and
a native menu trigger to FeedbackKit's web SDK. Setup instructions are in the
[plugin's README](https://github.com/tianhaoz95/feedback-kit/tree/main/desktop/tauri#readme).
