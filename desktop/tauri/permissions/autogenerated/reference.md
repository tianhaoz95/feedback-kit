## Default Permission

Lets the FeedbackKit plugin read the OS, device and app details it attaches to reports.

#### This default permission set includes the following:

- `allow-environment`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

</td>
<td>

</td>
</tr>

<tr>
